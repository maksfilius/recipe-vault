# M-04: минимальный экран рецепта

Проверено 12.11.2026 в локальном Chrome на 390×844 и 1440×900. Тестовые рецепты были доступны через временный маршрут, удалённый после проверки. Иллюстрация в полном рецепте — тестовый заполнитель.

- Полный рецепт: фото, название, источник, время, порции, Start cooking, описание, ингредиенты, шаги.
- Неполный рецепт: без фото, времени и описания; пустая строка метаданных не выводится.
- Русскоязычный рецепт: кириллица помещается по ширине; описание, повторяющее название, скрывается.
- На обеих ширинах нет горизонтальной прокрутки. Чипсы коллекций и тегов, дата обновления отсутствуют.
- Меню «⋯»: фокус переходит на Edit; стрелка вниз — на Delete; Escape закрывает меню и возвращает фокус. Delete открывает диалог подтверждения.
