# Задачи

Как пользоваться: правила для агентов описаны в [README.md](README.md). Задача готова, когда выполнены все пункты «Готово, когда». Размер: **S** — до полудня, **M** — 1–2 дня. Задачи больше M нужно дробить.

Префиксы: **A** — аналитика, **D** — дизайн, **M** — минимальный v1, **B** — баги, **W** — веб и хранилище, **E** — расширение, **G** — рост, **P** — платежи, **X** — импорт из соцсетей, **S** — сторы.
