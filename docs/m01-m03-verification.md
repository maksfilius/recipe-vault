# M-01–M-03: минимальная библиотека

Проверено 12.11.2026 на локальном Next.js через `localhost:3001` и Chrome.

- На 390×844 шапка занимает 65 px, первая карточка начинается на 82 px. Горизонтального скролла нет.
- Проверены сетки с 0, 1, 10 и 200 рецептами. На десктопе проверены 10 и 200 рецептов.
- Мобильный поиск раскрывается и получает фокус. Меню аккаунта открывается с фокусом на Settings, содержит Settings, Theme и Sign out, закрывается по Escape с возвратом фокуса.
- Переключение System/Light/Dark сохраняет выбор; после выбора Dark корневой элемент имеет класс `dark`.
- `/dashboard/favorites` возвращает `307` с `Location: /dashboard`.
- Временный маршрут с тестовыми рецептами удалён после снимков. Проверка с реальной сессией и браузерной кнопкой Back остаётся для приёмки на подключённом dev Supabase.
