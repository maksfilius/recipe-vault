# ADR 001: как расширение сохраняет рецепт (E-02)

**Статус:** принято 16.11.2026 на основе утверждённой спецификации [A-03](../specs/extension.md) (10–11.11.2026: «Save через веб» — Must, «прямой Supabase API из расширения» — Won't v1).

## Варианты

| | (а) Handoff через вкладку сайта | (б) Сессия Supabase в расширении через контент-скрипт | (в) `chrome.identity.launchWebAuthFlow` + свой токен |
|---|---|---|---|
| UX | Save открывает вкладку, рецепт проверяется в веб-редакторе и сохраняется явно | Сохранение не уходя со страницы | То же, что (б), плюс отдельный экран входа |
| Безопасность | В расширении нет токенов; черновик в URL-фрагменте, сервер его не видит | Токен Supabase копируется в расширение, отзыв только сменой сессии | Отдельный токен с отзывом, но нужен свой OAuth-сервер |
| Объём | Уже работает (v0.2.0) | API + CORS + обновление токена, M–L | Самый большой, L |
| Без аккаунта | Вход/регистрация на сайте с возвратом к черновику | Нужен свой UI входа в панели | Нужен свой UI входа |

## Решение

Вариант (а). Расширение — канал привлечения: получить рецепт и готовить можно без аккаунта, а сохранение приводит человека в веб-библиотеку, где он видит продукт и регистрируется. Редактор — финальная проверка перед Save, как требует спецификация.

## Поток

```text
панель Save → keepandcook.com/login#keep-and-cook-import=<рецепт без картинки>
  → library-handoff.js (document_start): валидация, sessionStorage
    keep-and-cook:pending-recipe-import + keep-and-cook:pending-recipe-source=extension,
    копия в localStorage на 7 дней для подтверждения email в другой вкладке
  → вошёл: /dashboard; нет: вход или регистрация с возвратом
  → редактор с черновиком → Save → проверка дубликата по source_url → карточка
```

Аналитика: `extension_handoff_completed`, `recipe_saved {source: extension}`, `signup_* {entry_point: extension}`.

## Последствия

- E-03 (API для расширения) и E-04 (вход в панели) — Won't v1. Вернуться, если данные покажут большой отвал между Save в панели и Save в редакторе.
- Обратный статус Saved / Already saved в панели (Should в A-03, бывшая E-07) требует сообщения из вкладки в расширение с привязкой к id передачи; делать после публикации.
- Фото передаётся как https-адрес и скачивается сервером при Save (с защитой от внутренних адресов на каждом редиректе). Если скачать не удалось, рецепт сохраняется без фото с уведомлением. После Save панель закрывается, проверка продолжается во вкладке сайта.
