# Библиотека рецептов после M-01—M-06

Текущий основной экран показывает сетку карточек и поиск по названию, ингредиентам и тегам. Новые рецепты идут первыми. Коллекции, теги и избранное остаются в данных, но элементы фильтрации и отдельная навигация по ним скрыты в минимальном интерфейсе.

Пустая библиотека предлагает поле ссылки и ручной ввод прямо на странице. Ручная форма открывается на том же экране: первый рецепт можно сохранить без диалога. Ниже есть ссылка на установку локального расширения Chrome. Пустой результат поиска показывает отдельное сообщение и кнопку очистки запроса.
