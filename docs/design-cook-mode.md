# D-10 · Cook mode в вебе

**Реализация и браузерная проверка: 11.11.2026.** Основа — утверждённые [веб-спецификация](specs/web.md), [спецификация расширения](specs/extension.md) и [правила PWA](pwa-v1.md).

## Поведение

- Cook mode занимает viewport. Верхняя строка показывает название, ингредиенты и выход; работающие таймеры остаются видимыми при переходе между шагами. Нижняя навигация находится над safe area.
- Длинный шаг делится по реально доступной высоте. «Continue step» меняет только часть текста, затем «Next step» меняет шаг. «Previous» возвращает к предыдущей части или последней части предыдущего шага. При повороте экрана сохраняется примерная позиция чтения.
- Ингредиенты открываются в шторке с нативными чекбоксами. Отметки хранятся до выхода из cook mode; шторка также показывает активные таймеры. Escape сначала закрывает шторку, затем cook mode. Tab удерживает фокус внутри активной области; после выхода фокус возвращается к «Start cooking».
- Таймер запускается только нажатием. Остаток всегда считается из абсолютного `endsAt`, после `visibilitychange` обновляется; звук и вибрация срабатывают при видимой странице. Wake lock освобождается при скрытии и запрашивается снова при возвращении. Отказ браузера в wake lock не прерывает готовку.

## Проверка

- `npm run test`: **71/71**; `npm run build`: успешно; `git diff --check`: без замечаний.
- Тестовый рецепт в Chrome: 390×844, 1440×900 и 900×450; светлая и тёмная темы. Горизонтального скролла нет, нижняя навигация видна. Временный маршрут с тестовым рецептом удалён после проверки.
- На 390×844 длинный шаг занял 4 части. Проход до второго шага сохранил весь текст без пропусков; «Previous» вернул к части 4 первого шага. После смены viewport на 900×450 позиция осталась возле того же фрагмента.
- В браузере с тестовыми часами два таймера показывали 10:00 и 30:00, после сдвига времени на 5 минут и `visibilitychange` — 5:00 и 25:00. С тестовым `navigator.wakeLock` проверены release при скрытии и повторный request при возвращении. Проверены чекбоксы, Escape, Tab и возврат фокуса.
