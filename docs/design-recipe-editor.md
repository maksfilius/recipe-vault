# D-07 — добавление и редактор рецепта

Диалог начинает с двух путей: импорт ссылки открывает редактируемый черновик, ручной ввод — пустую форму. Ссылка, введённая перед неудачным импортом, остаётся в ручной форме. При импорте показываются состояние загрузки и конкретная ошибка API с повтором или ручным вводом. В черновиках из URL и расширения перечислены отсутствующие фото, ингредиенты и шаги; название и описание обязательны при сохранении, остальные поля — нет.

Форма приведена к токенам D-01/D-02. Источник находится у названия, фото можно добавить по HTTPS-ссылке, а кнопка Save остаётся доступной при прокрутке. Сохранение блокирует повторное нажатие. Перед записью источника выполняется проверка дубликата; существующий рецепт открывается для просмотра и редактирования, а ошибка уникальности БД остаётся запасной защитой. После успешного Save открывается карточка; черновик расширения удаляется только после подтверждённой записи.

## Проверка

В изолированной копии приложения проверены ручная форма на 390/1440 px, частичный URL-импорт, ошибка 404 с сохранённой ссылкой и восстановление `importDraft` из localStorage. Ответы API и Supabase в этой проверке были временными тестовыми подменами, подключённая база не менялась. Тест Save подтвердил запись ручного рецепта с пустыми массивами ингредиентов и шагов, открытие существующего рецепта при дубликате и очистку черновика расширения после сохранения.
