# Добавление и редактор после M-04—M-06

Диалог «Добавить» начинает с одного поля URL и кнопки Import; рядом есть ссылка на ручной ввод. Ошибка импорта оставляет URL в поле и предлагает Retry или ручную форму. Импорт создаёт редактируемый черновик, который сохраняется только после явного Save. Для пустой библиотеки те же действия доступны прямо на странице; ручной ввод первого рецепта не открывает диалог.

Форма показывает название, источник, ингредиенты и шаги. Дополнительные метаданные сохраняются, но не перегружают первый экран. У рецепта после сохранения доступны просмотр, правка и режим готовки.
