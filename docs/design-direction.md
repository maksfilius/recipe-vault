# Дизайн-система Keep & Cook

**Статус: утверждено для D-01, 10.11.2026.** Это источник решений по цвету, типографике и базовым состояниям веба. Реализация токенов — [`src/app/globals.css`](../src/app/globals.css). Состав компонентов и экранов уточняют D-02…D-14; поведение — утверждённые [A-03](specs/extension.md) и [A-04](specs/web.md).

## Характер

Keep & Cook — личная кулинарная книга, которую удобно открыть у плиты. Интерфейс строится на тёплой бумажной поверхности, тёмных чернилах и одном цвете действия — терракоте. На рабочем экране важнее ясность рецепта и крупных управляющих элементов, чем декоративная выразительность. Фотографии еды остаются главным визуальным содержимым, поэтому фон, панели и списки плоские и спокойные.

Web и расширение должны читаться как один продукт. Текущий CSS расширения служит отправной точкой; перенос точных токенов и синхронизацию делает D-03. До этого значения там могут отличаться. Существующие градиенты и стеклянные слои отдельных старых экранов убираются при их задачах D-04…D-13; D-01 задаёт их замену и не меняет потоки этих экранов.

## Цветовые токены

Все значения HSL указаны как `H S% L%`, хранятся в `:root` и `.dark` и используются через `hsl(var(--token))` либо Tailwind semantic colors. Пара `primary`/`primary-foreground` рассчитана на текст кнопки; `primary` также проходит AA для обычной ссылки на `background` и `card`.

| Токен | Светлая тема | Тёмная тема | Роль |
|---|---|---|---|
| `--background` | `30 40% 92%` · `#f3ebe2` | `24 24% 9%` · `#1c1611` | Canvas приложения/PWA |
| `--card` | `36 70% 99%` | `25 20% 14%` | Панель, карточка, editor |
| `--foreground` | `268 20% 14%` | `30 28% 94%` | Основной текст |
| `--muted` | `30 22% 86%` | `25 15% 20%` | Вторичная поверхность, hover у тихих действий |
| `--muted-foreground` | `25 12% 37%` | `28 16% 72%` | Вторичный текст, disabled текст |
| `--border` | `28 18% 70%` | `25 13% 33%` | Разделители и поля |
| `--primary` | `18 80% 39%` · `#b34414` | `18 80% 64%` | CTA, ссылки, выбранное состояние |
| `--primary-hover` | `18 80% 34%` | `18 80% 69%` | Hover активного действия |
| `--primary-foreground` | `30 100% 98%` | `22 35% 10%` | Текст на primary |
| `--destructive` | `358 68% 44%` | `4 88% 74%` | Ошибка и удаление |
| `--destructive-foreground` | `30 100% 98%` | `24 24% 9%` | Текст на destructive |
| `--ring` | `var(--primary)` | `var(--primary)` | Видимый фокус |

Toast сохраняет инвертированную поверхность: в светлой теме тёмные `--toast`/светлый `--toast-foreground`, в тёмной — наоборот. `--toast-accent` и `--toast-danger` предназначены только для иконок/акцентов внутри toast. В D-09 удалён временный токен фотоподложки `--veil`.

У коллекций нет жёстких цветов по типу «завтрак/обед/ужин»: коллекции создаёт пользователь, и категория не должна определять цвет. Чип по умолчанию — `muted` с текстом `foreground` или `muted-foreground`; выбранный чип использует `primary` и `primary-foreground`. Старые `--cat-*-grad-*` и фиолетовый `--accent` удалены. Никаких градиентов для категорий.

## Контраст

Расчёт по WCAG 2.x для непрозрачных цветов, округление до 0.01. Обычный текст требует ≥4.5:1, крупный — ≥3:1; выбранные основные пары проходят обычный AA. Полупрозрачные старые панели и фото требуют отдельной проверки в D-14 на реальном фоне.

| Пара | Светлая | Тёмная |
|---|---:|---:|
| `foreground` / `background` | 13.88:1 | 15.76:1 |
| `foreground` / `card` | 16.14:1 | 13.65:1 |
| `muted-foreground` / `background` | 5.41:1 | 9.11:1 |
| `muted-foreground` / `muted` | 4.69:1 | 6.39:1 |
| `primary` / `background` — текст ссылки | 4.74:1 | 6.94:1 |
| `primary` / `card` — текст ссылки | 5.51:1 | 6.01:1 |
| `primary-foreground` / `primary` — CTA | 5.40:1 | 6.78:1 |
| `destructive` / `background` | 5.17:1 | 7.61:1 |

Не накладывать текст на полупрозрачный `primary/10` с предположением, что приведённые значения сохранятся: реальный цвет зависит от фона. На фото использовать непрозрачную поверхность под текстом либо отдельно проверить итоговый композит.

## Типографика

- **Выразительный голос:** локально размещённый variable [Fraunces](https://github.com/undercasetype/Fraunces) для `h1` и целевых больших заголовков (`--font-display`). Файл `public/fonts/Fraunces-Variable.woff2`, лицензия `public/fonts/OFL-Fraunces.txt` (SIL OFL 1.1). `font-display: swap`; Georgia — запасной вариант. Не использовать декоративный шрифт в списках ингредиентов, полях ввода и навигации.
- **Рабочий голос:** системный sans (`--font-sans`) для текста рецепта, форм и управления. `--font-mono` только для кода/числовых показаний таймера; числа в таблицах — `tabular-nums`.
- Шкала: 12px (служебный минимум), 14px (подписи), **16px** (основной текст), 20px (заголовок карточки), 24px (секция), 32px (экран), 48–64px (display на широком экране). На мобильном не уменьшать текст рецепта ниже 16px, управляющие подписи — ниже 14px. Для длинных шагов cook mode использует отдельную крупную шкалу из A-03.
- Основной текст: line-height 1.5–1.65, мера 65–75 знаков на описательных страницах. Заголовки: line-height 1.05–1.25, tracking не плотнее `-0.04em` (текущий `h1`: `-0.025em`). Короткие заголовки можно балансировать; длинные названия рецептов должны переноситься без обрезки в карточке и editor.

## Ритм, форма и состояния

- Базовый шаг отступов 4px; используемые интервалы: 4, 8, 12, 16, 24, 32, 48px. Внутри группы расстояние меньше, чем между группами. Библиотека и editor подчиняются одной шкале.
- Поля и управляющие элементы: радиус 12px (`--radius` / `--radius-xl`); карточки и диалоги: 16px (`--radius-2xl`), малые элементы: 8px. Минимальная интерактивная высота 44px. Пилюли — только для маленьких чипов/меток, не для больших карточек.
- Поверхности отделяются **одной** тонкой границей. Тень допустима у плавающего диалога/тоста; не совмещать широкую мягкую тень с границей на обычных карточках. Декоративные размытия и стеклянные панели заменяются плоскими поверхностями в задачах соответствующих экранов.
- Primary hover использует `--primary-hover`; тихий hover — `--muted`; active оставляет видимый контур/смену поверхности; disabled использует `muted` + `muted-foreground` и сохраняет читаемую подпись, а не одну только низкую opacity. Ошибка сочетает `destructive` с текстом и ясным сообщением, без передачи смысла одним цветом.
- `:focus-visible` — outline 3px `--ring` с offset 3px. Не скрывать его под `overflow: hidden`. Selection, caret, checkbox/radio accent и scrollbar используют семантические токены. Motion respect `prefers-reduced-motion`; переходы не должны блокировать чтение или навигацию.

## Границы D-01 и продолжение

Токены и типографика доступны сейчас, но часть старых экранов ещё содержит градиенты фона, полупрозрачные поверхности и жёстко заданные стили. Их визуальное обновление относится к D-02…D-14, без изменения данных и логики. D-03 переносит значения в расширение и добавляет проверку синхронизации. Контраст выше относится к базовым цветам; финальный визуальный QA проверяет реальные сочетания на каждом экране.
