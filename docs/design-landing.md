# D-09 · Лендинг

**Проверено 11.11.2026.** Страница `/` построена вокруг первого действия: вставить ссылку и увидеть черновик без аккаунта. Текст ориентирован на англоязычного домашнего повара из [A-02](research/audience.md); окончательная формулировка оффера может уточняться после G-01.

## Что изменено

- Первый экран объясняет импорт ссылки и сразу показывает рабочую форму. Существующий `POST /api/recipes/import` и передача черновика в редактор сохранены. Пустой, загружающийся, ошибочный и частичный результат явно подписаны.
- Ниже идут возможности библиотеки, блок Chrome-расширения и повторный CTA для создания аккаунта. Ссылка на источник остаётся частью обещания продукта.
- Расширение пока не опубликовано в Chrome Web Store. Кнопка **Add to Chrome** отключена и сопровождается текстом о будущем выпуске; рабочую ссылку нужно добавить в E-11.
- Лендинг и OG-картинка используют утверждённые токены D-01. Удалены две неиспользуемые PNG-фотографии размером около 5 МБ суммарно, их стили и hook прокрутки.

## Проверка

- `npm run test`: 66/66 тестов; `npm run build`: успешно.
- Lighthouse 13.6.0 на локальном production-сервере, mobile, категории Performance и SEO: **100 / 100**. Это локальный замер, не метрика продакшена.
- Chrome DevTools emulation: `documentElement.scrollWidth === clientWidth` при 390 и 1440 px; светлая и тёмная темы на телефоне.
- В браузере с подставным ответом `/api/recipes/import` проверено: результат «Citrus Pasta» показан в демо, нажатие «Open recipe» записало тот же черновик в `sessionStorage` для dashboard. Внешний сайт при этой проверке не запрашивался.
- Снимки: [телефон, светлая тема](screenshots/kc-d09-mobile-light.png), [телефон, тёмная тема](screenshots/kc-d09-mobile-dark.png), [десктоп, светлая тема](screenshots/kc-d09-desktop-light.png).
