# M-05: редактор из трёх полей

Проверено 12.11.2026 в локальном Chrome на 390×844 и 1440×900. Временный маршрут с тестовыми рецептами удалён после проверки.

- Ручной ввод: видны название, ингредиенты и шаги; источник, время, порции и описание раскрываются через «More details».
- Отправка формы только с названием даёт пустые массивы ингредиентов, шагов, коллекций и тегов; описание необязательно.
- Правка: строки `1/2 cup cream` и `2 lemons` восстанавливаются в textarea; при отправке сохранены прежние ID коллекций, теги и URL фото.
- Импортный черновик открывается в том же редакторе с исходными русскоязычными строками.
- На проверенных ширинах горизонтальной прокрутки нет. Закрепление кнопки сохранения убрано, чтобы она не перекрывала дополнительные поля.
- Unit-тесты проверяют разбор строк, дробные количества, пустые строки, передачу скрытых данных в `save_recipe` и сохранение одного названия.
