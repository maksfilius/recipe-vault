# Роадмап

Порядок жёсткий: каждый этап начинается после критериев выхода предыдущего. Внутри этапа задачи идут параллельно по графу зависимостей из [tasks.md](tasks.md).

## Этап 0. Аналитика (≈1–2 недели)

Цель — решить, *что* строим, прежде чем строить.

- Конкуренты, аудитория, JTBD (A-01, A-02)
- Функциональная спецификация расширения (A-03) и веб-версии (A-04)
- Базовая точность парсера на топ-50 сайтов (A-05)
- План событий продуктовой аналитики (A-06)
- Исследование импорта из видео и соцсетей (A-07), пока только исследование
- Обновлённый `PRODUCT.md` (A-08)

**Выход:** утверждены `docs/specs/extension.md` и `docs/specs/web.md`, PRODUCT.md обновлён.

## Этап 1. Фундамент (≈4–6 недель)

Три параллельных потока.

**Дизайн (D-*)** — новый плоский дизайн для веба, PWA и расширения.
**Хранилище (W-*)** — рефакторинг дашборда, общий rate limit, улучшения парсера, онбординг, аналитика, мониторинг, E2E, Web Share Target для PWA (W-12: «Поделиться → Keep & Cook» на Android).
**Расширение (E-*)** — прямое сохранение, состояние «уже в библиотеке», картинки, таймеры, локализация, упаковка и публикация в Chrome Web Store.

**Выход:**
- Весь веб и расширение в новом дизайне, light и dark, мобильная и десктопная вёрстка.
- Расширение опубликовано в Chrome Web Store.
- Парсер справляется с ≥80% сайтов из топ-50 (по A-05).
- События воронки приходят в аналитику, ошибки — в мониторинг.
- Rate limit общий для всех инстансов.

## Этап 2. Привлечение (≈4–8 недель)

- Стратегия продвижения и монетизации (G-01) — отдельный документ, задача стартует уже в этапе 0–1, параллельно
- Лендинг, SEO, ASO в Chrome Web Store, запуски (Product Hunt, Reddit, Show HN)
- Обратная связь: форма в приложении, опрос при удалении расширения
- Лист ожидания Pro, чтобы проверить готовность платить
- Письма жизненного цикла
- **Импорт из YouTube (X-01)** — бесплатно с лимитом, чтобы измерить спрос и себестоимость до решения о цене. Работает и из поля ссылки, и через «Поделиться» (W-12)

**Выход (ориентиры, уточняет G-01):** ≥500 регистраций, ≥100 WAU, ≥40% новых пользователей активированы (≥3 рецептов), ≥50 email в листе ожидания Pro, известны доля рецептов из видео и стоимость одного импорта.

## Этап 3. Монетизация

- Решение по цене и лимитам на данных этапа 2 (P-01)
- Биллинг (Paddle или Lemon Squeezy), подписки, проверка доступа
- Paywall на импорт из видео (X-02), TikTok и Instagram (X-03)
- Страница цен, юридические документы

**Выход:** ≥10 платящих пользователей.

## Этап 4. Сторы

Только после этапа 3. Сначала исследование (S-01): PWA-обёртка (TWA или Capacitor) против нативного приложения, требования сторов к подпискам.
